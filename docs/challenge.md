1. Escenario y Desafío
Imagina esto: te han nombrado como el Director de Enlaces del Internet 🌐 (sí, de todo el internet).

Tu tarea: construir una app para organizar enlaces y recursos antes de que la web se derrumbe en el caos y solo nos queden memes de gatos 🐈.

Tienes dos semanas. Sin presión.

Tu jefe — una extraña combinación de bibliotecario gruñón y un gato muy real 🐈 — insiste en que construyas esta app dos veces:

Primero con Vanilla JS puro, porque el gato cree que nadie debería usar un framework sin entender qué hay debajo.
Luego con React, llevando todo a una arquitectura de componentes sólida y reutilizable.
Si parece exagerado, es porque lo es. Pero es lo que quiere el gato. Y tu trabajo es complacer al gato.

🧠 Habilidades que necesitas aprender
Habilidad	Descripción
Vanilla JS / ES6	La base de todo. Sí, existe. No, no sabe a helado.
React	Componentes reutilizables, gestión de estado, comunicación entre capas y mini aplicaciones integradas dentro del mismo ecosistema.
Tolerancia al sufrimiento	Incluida sin costo adicional.
✅ Requisitos obligatorios
📁 Recolectar enlaces: Permite a los usuarios guardar enlaces y añadir etiquetas 🌱, porque todo en la vida necesita un buen tag.
💬 Añadir comentarios y votos: Los usuarios deben poder comentar y votar enlaces, porque incluso en internet, la democracia importa 🏛️.
🖥️ Dos vistas integradas: Una para navegar los enlaces (con filtros por etiquetas) y otra para mostrar el detalle de cada enlace, incluyendo comentarios y votos, todo como componentes dentro del mismo entorno React.
🔌 Conexión a un backend común: La app debe consumir un servidor compartido a través de una API RESTful.
⚡ SPA (Single Page Application): La app debe ser una aplicación de una sola página, sin renderizado en servidor al navegar entre vistas.
🚀 Entregables y Reglas
Un repositorio principal con el backend y un README claro que explique cómo instalar y ejecutar el proyecto completo.
El frontend debe estar construido en React con componentes reutilizables y bien organizados, integrando todas las funcionalidades dentro del mismo entorno.
README detallado: explica cómo instalar, ejecutar y desplegar la app. La buena documentación es clave, porque el pobre alma que lea tu código te lo agradecerá.
Buenas prácticas: RESTful, código limpio, manejo de errores, separación de responsabilidades. El gato lo nota.
📋 Orden de desarrollo sugerido
Comienza con el servidor
Construye la base en Vanilla JS para entender la lógica pura
Migra e integra todo dentro de React como componentes
